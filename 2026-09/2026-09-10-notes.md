  * Rebuilt the VM with Legacy BIOS + registry bypass (instead of UEFI like previously)

    * 60GB virtual hard disk
    * 4GB RAM
    * 2 CPU cores
    * Enable EFI unchecked -> VM in Legacy BIOS mode
    * Graphics Controller set to VMSVGA/VBoxVGA (ignore warning) and Video Memory at least 128MB
    * Network

      * Adapter 1: Host-only Network (same as Kali and Metasploitable2)
      * Adapter 2: NAT (disconnected during setup for account setup)
    * Registry bypass

      * First Windows Setup screen appears -> press Shift + F10
      * Type 'regedit' in command prompt window
      * In the Windows Registry Editor GUI navigate to HKEY\_LOCAL\_MACHINE -> SYSTEM -> Setup (click once)
      * Create new key name 'LabConfig' (case does not matter, but spelling does)
      * In new LabConfig key create the following DWORD (32-bit) Values: 'BypassTPMCheck', 'BypassSecureBootCheck', 'BypassRAMCheck'
      * Double click each value and set "Value data" from 0 to 1
      * Close windows and continue setup
